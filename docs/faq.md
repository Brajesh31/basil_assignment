# FAQ

## Does this process real refunds?

No. The refund button is currently a UI element with no connected payment service.

## Does it need a database?

Not in its fixture-only form. A production dashboard needs an authenticated backend and persistent source of truth.

## What starts the app?

`npm start` starts the Create React App development server.

## Which routes are available?

The dashboard is `/`; order details use `/order/:order_id`.

## Where should I report a vulnerability?

Use the private process in [SECURITY.md](../SECURITY.md).
