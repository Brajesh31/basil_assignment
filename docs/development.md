# Development

Use two-space indentation for TypeScript, JavaScript, JSX, and JSON. Keep reusable UI in `src/components/`, route-level behavior in `src/pages/`, and Redux state in `src/redux/`.

Prefer typed props and selectors, stable list keys, accessible controls, and explicit loading, error, and empty states. Keep fixtures synthetic.

```powershell
npm test
npm run build
```
