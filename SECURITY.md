# Security Policy

This repository is a frontend prototype using local fixtures. It has no authentication, authorization, backend API, payment processing, or server-side validation. The visible refund action must not be treated as a completed financial operation.

Do not add real customer records, contact details, payment identifiers, credentials, or tokens to fixtures, screenshots, issues, or commits. When a backend is introduced, use authenticated requests, least-privilege authorization, server-side refund validation, audit logs, privacy controls, and safe errors.

Do not publish sensitive details in an issue. Contact Brajesh Kumar privately through <https://github.com/brajesh31> with sanitized reproduction steps, impact, and affected route or component.
