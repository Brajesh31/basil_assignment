# Support

This frontend prototype is maintained on a best-effort basis.

Read [docs/installation.md](docs/installation.md), [docs/development.md](docs/development.md), and [docs/faq.md](docs/faq.md) first. Include browser, Node.js version, route, reproduction steps, and sanitized console output when reporting a problem.

Never attach real customer data, payment identifiers, or access tokens. Report vulnerabilities through [SECURITY.md](SECURITY.md).
